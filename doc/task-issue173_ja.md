[English](task.md)

日付: 2026-10-10
追跡: [Issue #173](https://github.com/kkamegawa/vsextensionforcodex/issues/173)

- 既存の英日対話設計を更新し、Check status で MCP 詳細を展開し、常時表示する MCP details トグルで展開状態を切り替える仕様を記録しました。Gateway の概要・回復操作と Check status は残します。
- シリアライズ対象の展開状態と常時表示の MCP details トグルを追加しました。トグルのチェック状態は詳細の展開状態と一致し、折りたたんでも操作中のコントロールが消えず、キーボードフォーカスを保ちます。折りたたみでは認証状態や保留中の操作を破棄せず、通知や処理中の照会応答でも開き直しません。owner の破棄では初期表示へ戻します。
- 再表示、操作の保持、非同期応答・通知、owner 切り替えと古い応答、埋め込み XAML を検証する回帰テストを 4 件追加しました。既存の画像テストのルート検出も Git worktree の `.git` ファイルに対応させました。
- Release ソリューションのビルドは警告 0・エラー 0。追加テストは 4 件成功、UI 全体は 378 件成功・1 件スキップ、Core 全体は 402 件成功・5 件スキップでした。スキップは環境で利用できないファイルシステムリンクを要するケースです。
- VSIX 内の拡張 DLL と Release 出力、および埋め込み XAML とソースの一致を確認しました。実際の認証 XAML を使った WPF のオフスクリーン描画で、幅 700／380 ピクセル、Light／Dark／High Contrast の配色と展開・折りたたみ・再表示を目視確認しました。この確認は Hide status 実装時のもので、最終的なトグルの描画確認ではありません。証跡は `artifacts/hide-auth-status/` にあります。
- PR #175 のレビュー指摘に対応しました。トグルのラベルを MCP details とし、チェック状態を展開状態へ双方向にバインドしました（未使用の Hide コマンドとトグル用コマンドは削除）。`RoundButtonStyle` を `ButtonBase` 対象にしてトグルと共有し、無効時・ホバー時の表示を揃えました。折りたたみで保留中の MCP のサインイン・認証・破棄操作が隠れる間は、コンパクトな領域にヒントを表示します。1 ファイル専用の `.gitattributes` 規則を削除し、保留操作の追跡を含む回帰テスト 5 件に強化しました。
- レビュー対応後に再検証しました。Release ソリューションのビルドは警告 0・エラー 0、UI 全体は 380 件成功・スキップ 0、Core 全体は再実行で 407 件成功でした（初回の 1 件の失敗は再現せず、対象は特定できていません）。最終的な認証 XAML を WPF でオフスクリーン描画し、幅 700／380 ピクセル、Light／Dark／High Contrast の配色で、保留操作ありの折りたたみ・展開・保留操作なしの折りたたみを目視確認しました。証跡は `artifacts/issue173-mcp-details/` にあります。ハーネスが配色・継承される前景色・表示データを提供しており、Experimental Instance 内の統合動作や実際のテーマ切り替えを確認したものではありません。

不具合修正のため既存設計を更新し、機能計画の Wiki ページは追加していません。別途報告された `/goal` 実行中に Stop が表示されず中止できない問題は [Issue #174](https://github.com/kkamegawa/vsextensionforcodex/issues/174) に登録し、この PR の実装には含めていません。
