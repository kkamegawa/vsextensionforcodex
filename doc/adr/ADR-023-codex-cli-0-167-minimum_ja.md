# ADR-023: Codex CLI の最低 0.167.0、ターゲット 0.169.0

[English](ADR-023-codex-cli-0-167-minimum.md)

- 日付: 2026-11-16
- 状態: 承認済み
- 追跡: [Issue #268](https://github.com/kkamegawa/vsextensionforcodex/issues/268)([#274](https://github.com/kkamegawa/vsextensionforcodex/issues/274)、[#276](https://github.com/kkamegawa/vsextensionforcodex/issues/276))。実装は [Issue #270](https://github.com/kkamegawa/vsextensionforcodex/issues/270) と [Issue #272](https://github.com/kkamegawa/vsextensionforcodex/issues/272)
- 関連: [ADR-011](ADR-011-app-server-contract.md)、[ADR-020](ADR-020-app-server-0-166_ja.md)、[ADR-022](ADR-022-visual-studio-2026-dotnet-10_ja.md)

## 背景

Codex CLI は 2026-11-06 から 2026-11-13 の間に 0.167.0、0.167.1、0.167.2、0.168.0、0.169.0 をリリースしました。2026-11-16 の時点で最新の安定版は 0.169.0 で、0.171.0 はアルファ版だけでした。拡張機能は 0.161.0 から 0.166.0 に対応し、5 つのバージョンティアとそれぞれのフォールバックを持っていました。すべてのパッチリリースを固定すると、プロトコルの確認範囲は広がらないまま、回帰確認の組み合わせだけが増えます。

0.166.0、0.167.0、0.167.2、0.168.0、0.169.0 について、公開された Windows 実行ファイルをリリースのダイジェストで検証し、stable と experimental のサーフェスのスキーマを生成しました。

- 0.167.0 と 0.167.2 は、両サーフェスで同一のスキーマを生成します。違いは生成メタデータだけです。
- 0.166.0 から 0.169.0 で削除されたメソッドはありません。追加と形の変化は [app-server-0-169-design_ja.md](../app-server-0-169-design_ja.md) に記載します。

## 決定

- **最低バージョン:** ローカルとリモートのサーバーとも 0.167.0 です。0.167.x はすべて接続できます。0.167.0 未満は `initialize` の後、`initialized` の前に拒否します。
- **ターゲット:** 0.169.0 です。
- **固定するリリース:** 固定して検証するのは各マイナー系列の最新パッチだけで、回帰確認は 0.167.2 と 0.168.0、ターゲットは 0.169.0 です。0.167.0 は固定しません。固定しているマイナー系列に新しいパッチがリリースされた場合は、固定するパッチをそちらに置き換えます。
- **マニフェストの検証:** `minimumVersion` は、固定した最古のリリースと同じマイナー系列にあり、それを超えてはなりません。回帰確認バージョンや固定リリースであることは要求しません。
- **機能ティア:** `Unsupported`、`Baseline`(0.167)、`Tier168`、`Tier169` です。0.163 から 0.166 のゲートとそのフォールバックは削除します。各ティアは自身の導入バージョンと比較します。
- **検証しない 0.167.x の根拠:** 0.167.0 と 0.167.2 のスキーマが同一であることを、0.167.0 と 0.167.1 が検証済みの 0.167.2 とプロトコル互換である根拠とします。

## 代替案

- **最低バージョンを 0.161.0 のままにする。** 不採用です。5 つのティアとフォールバックが残ります。また ADR-022 のプラットフォーム変更により、どの利用者も新しいリリースをインストールすることになります。
- **0.167.0 を最低バージョンとして固定する。** 不採用です。スキーマが 0.167.2 と同じで、後のパッチで実行時の修正が入っている回帰確認バージョンが増えるだけです。
- **最低バージョンを 0.167.2 にする。** 不採用です。0.167.0 と 0.167.1 は同じプロトコルを使うため、拒否しても安全性は上がりません。

## 結果

- 0.166.0 以前の利用者は、接続する前に CLI を更新する必要があります。
- 0.167.x の中でスキーマを変えない動作の違い(実行時の修正など)は、0.167.2 の検証だけで確認します。
- 契約マニフェスト、スクリプト、Fake app-server、テスト、セットアップ文書は新しいバージョンを使います。

## 決定の履歴

- 2026-11-16: 承認。メンテナーが 2026-11-15 の実装計画でバージョン方針を承認しました。0.167.0 と 0.167.2 の比較結果も同日に記録しました。
